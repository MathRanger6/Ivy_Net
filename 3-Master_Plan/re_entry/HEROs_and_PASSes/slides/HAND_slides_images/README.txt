HAND_slides_images/ — JPEG exports of CHAR_Phase_B_characterization_HAND.pptx
================================================================================

Files: Slide1.jpeg … Slide16.jpeg (one per slide; PowerPoint default naming).

Purpose
-------
Visual snapshot of the hand-edited deck for agents and reviewers. Equation
Editor math and fine layout in the .pptx are not readable from scripts/XML;
these JPEGs are the source of truth for "what the slide actually looks like."

Maintenance (Charles)
---------------------
1. Edit slides/CHAR_Phase_B_characterization_HAND.pptx in PowerPoint.
2. Export / Save as Pictures into this folder (overwrite SlideN.jpeg).
3. Re-export after substantive notation, text, or layout changes.
