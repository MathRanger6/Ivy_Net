## Working frame for the synthesis (proposal — not agreed)

Peers **and organizations** can enter individual success through three channels:

| Channel | Peers | Organization | Approximate project mapping (BINDING memo) |
|---------|-------|--------------|---------------------------------------------|
| **Development** (what a person becomes) | Model excellence; raise the standard of practice | Coaching, facilities, medical care | Environment (`L_net = B − D`) |
| **Evaluation** (how a given performance is measured or perceived) | Set the comparison standard; share minutes, shots, top ratings | Prestige and visibility shape how scouts, boards, committees read the same performance | Scoring (`S_i`) |
| **Selection** (who wins a scarce slot) | Compete for the same slots | Sets slot count and rules: roster size, rater profiles, tenure lines | Winner rule (top K, later stochastic) |

The current competitive model holds input performance fixed, so development belongs to the motivation, not to the model.

**Identification caveat to state in the background:** the HERO peer mean cannot by itself separate peer from organizational contributions. Manski (1993): endogenous effects (peer behavior), contextual effects (peer characteristics), correlated effects (shared characteristics or similar institutional environments). Duke teammates ≈ endogenous/contextual; Duke facilities and coaching ≈ correlated.

**Network-science bridge for organizations (candidates):** affiliation (bipartite) networks of persons and groups (Breiger 1974); prestige measured from the faculty hiring network (Clauset, Arbesman & Larremore 2015).

**Terminology (settled 16:50, Charles):** in the introduction, "environment" = peers + organization across all three channels; **development** is a subset of environment. Note that BINDING uses "environment" for the development channel only; spell out the difference if both documents are cited together.
