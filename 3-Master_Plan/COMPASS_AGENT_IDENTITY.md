# COMPASS — cross-project planning agent

**Effective:** 2026-06-11  
**Decided by:** Charles Levine

## Name change

The cross-project planning agent was originally called **Master Planner** in filenames and prose (`Master_Planner_*`, `*_report_to_master_planner.md`, `Planner_to_*_questions.md`).

As of **2026-06-11** it is named **COMPASS** (alongside **CODA**, **SCOUT**, **PEER**, **VECTOR**). Files were renamed; see table below.

**Why COMPASS:** Orientation and coherence across domains — dependencies, shortest defensible path, claim language — without owning domain code, analysis, or manuscript prose.

## File naming conventions (current)

| Pattern | Example |
|---------|---------|
| Operating guidance | `COMPASS_Initial_Guidance_v6.md` (canonical; older `v2`–`v5`, `COMPASS_Initial_Guidance.md` = historical) |
| Phase guidance | `COMPASS_Phase1_Guidance.md`, `COMPASS_Phase2_Guidance.md` |
| Agent handoff **to** COMPASS | `{AGENT}_report_to_COMPASS.md` |
| COMPASS questions **to** agents | `YYYYMMDD_HHMM_COMPASS_to_{AGENT}_questions.md` |
| COMPASS review / status | `20260611_COMPASS_Initial_Review.md`, `PROJECT_STATUS_AND_NEAR_TERM_PLAN.md` |
| Advisor plan update (Charles → Alex) | `20260611_Brief_for_Alex_Gates_brief.md` (one page), `20260611_Brief_for_Alex_Gates_full.md` (detail) |

## Legacy names

Historical PDF exports may still use old filenames until regenerated. Body text in archived guidance versions (`v2`–`v5`) has been updated to **COMPASS** where edited; **v6** is canonical.
