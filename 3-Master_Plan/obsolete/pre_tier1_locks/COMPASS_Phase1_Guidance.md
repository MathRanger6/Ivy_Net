## Purpose

Before building a comprehensive master plan, first develop a thorough understanding of the project and create a practical near-term roadmap.

The immediate priority is:

1. Complete the minimal model
2. Generate non-obvious predictions
3. Validate those predictions where possible
4. Write and submit the core manuscript

Future network-science extensions, dissertation expansion, and broader research-program planning should be tracked but not allowed to distract from these objectives.
