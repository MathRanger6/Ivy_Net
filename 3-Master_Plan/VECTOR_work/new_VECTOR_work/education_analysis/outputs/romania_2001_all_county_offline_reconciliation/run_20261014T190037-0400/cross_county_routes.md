# Cross-county routes

Counties included: 41 of 41 inventory units. A pair count uses School Result View rows whose destination label ends in another county code, and incoming admitted rows whose origin-school label ends in another county code.

Equal aggregate counts do not prove that the same people appear on both sides. Aggregate row counts include rows that lack a printable name or admission score. Those rows are absent from the key comparison. A unique name-and-score key is one printed name and admission score that occurs once on each side. The archived personal identifier is masked, so even a unique key is provisional.

Pairs with any saved count: 518. Aggregate counts agree: 500.
Pairs where both sides have complete known pages: 489. Those aggregate counts agree: 472.

This comparison does not authorize a national outcome analysis.
